## UniPath

**Επισκόπηση Έργου**

Το UniPath είναι μια εφαρμογή που αναπτύχθηκε σε περιβάλλον NetBeans με χρήση της γλώσσας προγραμματισμού Java. Στόχος του έργου είναι να υποστηρίξει τους μαθητές λυκείου στη διαδικασία επιλογής της κατάλληλης πανεπιστημιακής κατεύθυνσης, παρέχοντάς τους καθοδήγηση για την εκπαιδευτική και επαγγελματική τους πορεία.
Μέσω της εφαρμογής, ο χρήστης έχει τη δυνατότητα να εξερευνήσει διαθέσιμες πανεπιστημιακές επιλογές, να δεχτεί προτάσεις βασισμένες στα ενδιαφέροντά του και να υποβάλει αίτηση εγγραφής σε τριτοβάθμια ιδρύματα.
Ο τίτλος του έργου "UniPath" προέρχεται από τη σύνθεση των λέξεων "University" και "Path", υποδηλώνοντας τον δρόμο του μαθητή προς την Ανώτατη Εκπαίδευση.

**Οδηγίες Εγκατάστασης**
1.	Κατεβάστε ή κάντε clone το repository στον υπολογιστή σας:
1.	Ανοίξτε το NetBeans IDE.
2.	Από το NetBeans, επιλέξτε	File → Open Project.Μετά,επιλέξτε τον φάκελο του έργου UniPath και πατήστε Open.
3.	Περιμένετε να φορτωθεί πλήρως το έργο.

**Οδηγίες Χρήσης**
1.	Μετά το άνοιγμα του project στο NetBeans, πατήστε το κουμπί "Build Project" .
2.	Για να εκτελέσετε την εφαρμογή, πατήστε "Run Project" ή το κουμπί F6.
3.	Η εφαρμογή περιλαμβάνει τα use cases από 1 έως 10, επιτρέποντας στο χρήστη να αλληλεπιδράσει με τις βασικές λειτουργίες της πλατφόρμας.

**Προϋποθέσεις**

1)Java JDK 8 ή νεότερο

2)Apache NetBeans IDE

3)Windows/Linux/macOS
